# aura-asr

Транскрипция командных созвонов с атрибуцией говорящих на Radxa Rock 5B.
Потребитель результата — слой AI-агентов, читающий `export/<call_id>.jsonl`.

**Главный документ — [SPEC.md](SPEC.md). Читать перед любой работой по коду.**
Он содержит все принятые решения; догадываться и выбирать умолчания вместо него
не нужно. `QUESTIONS.md` — история вопросов к версии 2 спеки, справочная.

Задачи ведутся в `postusername/aura-ops` под меткой `asr`: ASR-00 … ASR-07.
Этапы строго последовательны, ASR-(N+1) не начинается до приёмки ASR-N.

## Рабочие правила

- Лениво (ponytail, full). Stdlib и уже установленные бинарники раньше новых
  зависимостей. Меньше файлов лучше, чем больше. Абстракций не заводить, пока
  нет второй реализации.
- Код в одном файле `asr.py`, пока он меньше примерно 1000 строк.
- Комментарии, докстринги и тексты ошибок — по-русски.
- TDD: тесты вперёд кода, `unittest` из stdlib, без фикстур и внешних фреймворков.
  CI гоняет только юнит-тесты — моделей и аудио в репозитории нет.
- Осознанные упрощения помечать `ponytail:` с указанием потолка и пути апгрейда.
- Не упрощать: валидацию манифеста и входных файлов, обработку ошибок, ведущую к
  потере уже посчитанного транскрипта.
- Все числа по производительности — измеренные на этой плате, на русском аудио.
  Чужие бенчмарки в решения не переносить.
- При неопределённости, меняющей архитектуру, — остановиться и спросить.

## Окружение платы

- RK3588, 16 ГБ, Ubuntu aarch64, Python 3.12.3 системный, всё под root.
- Пакеты из apt, venv не заводим: диск маленький. Внешняя зависимость одна —
  `numpy`. `jiwer` только для `bench.py`.
- sherpa-onnx — готовые aarch64-бинарники из релизов, работаем через CLI и
  разбираем вывод. Python-биндинги не используем.
- whisper.cpp собирается из исходников, работает в режиме `whisper-server`,
  модель грузится один раз за прогон.
- Ночной прогон занимает 7 ядер из 8, governor `performance`.
- Корневой каталог данных задаётся в `config.toml`.

## Станция с GPU

`etu-pc-1`, root, Ubuntu 24.04, одна RTX A5000, CUDA 13.2, драйвер 595.71.05,
сеть ≈78 Мбит/с. Используется только на этапе 1.5 и только как «rsync + ssh +
одна команда». По умолчанию `[gpu] enabled = false`.
